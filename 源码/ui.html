运算符（大小写都行，前后留空格）
AND 两个词都要有　OR 出现任一个即可　 NOT 或前缀 - 排除　( ) 分组改变优先级
字段前缀（写了就覆盖上面的「字段」下拉）
title: 标题　abstract: 摘要　 tiab: 标题+摘要　fulltext: 全文
精确短语用英文双引号："lipid oxidation"　 不加引号时按分词处理，命中会宽松很多
直接定位：粘 DOI（10.1111/ijfs.15747 或 https://doi.org/…）、 W…（OpenAlex ID）、pmid:12345 都行，会直接查出那一篇，不当作关键词搜
通配符 * 匹配任意后缀、? 匹配单个字符。 只能用在词尾，程序会自动切到不词干化的 exact 字段：
tiab:shrim*　→ 同时命中 shrimp / shrimps / shrimplike　·　 title:antioxid*　→ antioxidant / antioxidants / antioxidative
注：普通词已由 OpenAlex 自动做词干化（shrimp 与 shrimps 同结果）， 通配符主要用于一个词根下差异较大的词形
文献类型（上面「类型」下拉，检索时生效）
研究论文 / 综述 / 学位论文 / 预印本 / 图书章节 / 不限类型。 综述单独选时才查得出来——以前默认只查研究论文，综述是搜不到的。
注：OpenAlex 对综述标注得不全（很多综述被标成研究论文）， 所以只选「综述」结果会偏少；要全一点用「研究论文 + 综述」， 标题里带 review / survey / overview 但被标成研究论文的，列表里会挂「疑似综述」灰标
