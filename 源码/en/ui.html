Exact phrase: use English double quotes: "lipid oxidation" Without quotes, terms are tokenized and matches get much looser
Direct lookup: paste a DOI (10.1111/ijfs.15747 or https://doi.org/…), W… (OpenAlex ID), pmid:12345 also work - it looks up that exact record instead of running a keyword search
Wildcards * matches any suffix, ? matches a single character. Only valid at the end of a term; the app switches to the non-stemmed exact field automatically:
tiab:shrim* → also matches shrimp / shrimps / shrimplike · title:antioxid* → antioxidant / antioxidants / antioxidative
Note: OpenAlex already stems ordinary terms (shrimp and shrimps give the same results), so wildcards are mainly for word forms that differ a lot under one root
